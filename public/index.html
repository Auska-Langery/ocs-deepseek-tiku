四步接入 OCS

这是 OCS Desktop（ocsjs 5.0）的题库配置，粘贴即用，不需要装插件。

  1. 启动题库：双击 启动题库.cmd，看到“监听地址”就说明服务起来了（窗口别关）。
  2. 填 API Key：在「设置」里粘贴 DeepSeek 的 Key，点“保存设置”，再点“测试连接”确认能通。
  3. 粘贴配置：复制下面的 JSON → 回到正在挂课的页面 → 打开「OCS 网课助手」悬浮窗的 「通用」→「全局设置」→ 找到 题库配置（按钮上写着“N 个可用题库（点击进入配置）”）。 如果按钮右边有 「⋯」，先点它选 「自定义题库」，别直接点主按钮—— 主按钮打开的是官方一键获取面板，里面只会显示你已经有的题库，看不到输入框。 然后在「题库配置填写/修改区」里粘贴 → 点 「保存配置」。
  4. 开始答题：OCS 会自动把题目发到本机题库；答过的题会记进本地题库，下次秒回、不花钱。

题库配置（复制这段）

常见问题

为什么用 GM_xmlhttpRequest，而不是 fetch？
答题页是 https 网页，从页面里直接 fetch 到 http://127.0.0.1，浏览器会把它当成 跨域 / 私有网络请求拦掉，面板上就显示 TypeError: Failed to fetch。 OCS 内置的脚本猫提供 GM_xmlhttpRequest，由扩展后台代为请求，不受页面跨域、CSP 和混合内容限制，所以稳定可用。 本题库的接口同时也开了 CORS：万一你的环境里没有 GM 接口，把配置里的 "type" 改回 "fetch" 也能用。
题库那一行显示 TypeError: Failed to fetch？
只有两种可能：①题库服务没开（双击 启动题库.cmd，黑窗口留着）；②配置里的 "type" 还是 "fetch"，被浏览器拦了 （改成 "GM_xmlhttpRequest"）。判断方法：浏览器打开 /api/ping 有 JSON 就是服务正常。
保存了，但 OCS 里的题库还是原来那个？
九成是点错入口了：题库配置这一行，主按钮打开的是「官方题库」一键获取面板，只会列出你已有的题库（比如言溪题库）， 里面没有输入框。要点按钮右侧的 「⋯」→「自定义题库」，才是有文本框、有「保存配置」按钮的那个弹窗。 保存成功后按钮文字会变成「N 个可用题库」，再刷新一下挂课页面即可。 另外：粘贴的新配置会整体替换原来的题库；想两个都留着，就把两份配置放进同一个数组里（中间加逗号）， OCS 会并发查询所有题库。
顶部黄色提示说“当前题库配置暂不支持图片、公式等题目处理”？
这不是报错，是 OCS 的「图片题优化」兼容性提示：它发现你开了图片题优化，但这个题库配置没有声明 ${images} 等图片字段，所以提醒你图片题优化不会生效（官方注释：仅提示，不限制）。 DeepSeek 本来也看不了图，直接点提示右上角的 × 关掉即可，同一份配置不会再弹； 想彻底不出现，就到「通用 → 全局设置 → 自动答题设置」把 图片题优化 取消勾选。
判断题、填空题怎么返回？
判断题返回“对 / 错”（或选项原文，如“A. 正确”）；填空题多个空用 # 分隔，例如 80#443。多选返回选项原文并用 # 连接，OCS 会自动拆开勾选。
图片题能答吗？
不能。DeepSeek 文本模型不支持看图，本服务也不会把图片上传。图片题请在 OCS 里关掉“图片题优化”，交给别的题库或跳过。
简答题答案挤成一行 / 编程题的 #include、<stdio.h> 丢了？
OCS 是把简答/编程题的答案当 HTML 塞进富文本编辑器的（body.innerHTML = answer）， 所以换行会被折叠、<stdio.h> 会被当标签吃掉、#include 还会被 OCS 当成多空分隔符切开。 本服务已自动处理：编程题整段转义并把换行写成 <br>、代码里的 # 写成 &#35;， 多行简答把换行写成 <br>，单行填空（如 80#443）保持纯文本。 到「设置 → 答题策略」可以关掉「简答 / 编程题答案转成 HTML」。
为什么有些题直接空着不答？
两类题会被主动跳过：① 题干要求「截图 / 拍照 / 画图 / 上传图片」——OCS 只能填文字，答了也没用； ② 题干里带图（“如图”“下图”“【图片】”）——模型看不到图，硬答基本是错的。 两者都在「设置 → 答题策略」里，可以单独关掉。被跳过的题不消耗 token、也不写进题库。
端口被占用 / 想换端口？
先试 重启题库.cmd（会结束占用 8787 的旧实例再启动）。要换端口就编辑 config.json 里的 port（或启动时加 --port 8888），重启服务，然后用新地址重新打开本页、重新复制上面的配置。
题库数据存在哪？会被上传吗？
全部存在 data/bank.json，只在本机。除了把题目发给 DeepSeek 换答案，不会上传到任何第三方。
